## 3. 핵심 발견 사항

### 3.1 버그 (수정 필요)

1. **TC089 — 비활성 자원 예약 허용**: `isActive=false` 자원에 예약이 생성됨. `scheduler-service`의 예약 생성 로직에 자원 활성 상태 검증 추가 필요.

2. **TC094 — APPROVED→REJECTED 전환 허용**: 이미 승인된 예약이 반려되는 문제. 상태 전환 맵에서 APPROVED 이후 REJECTED로 전환 불가하도록 제한 필요.

3. **TC074 — 소유자 인벤토리 삭제 불가**: researcher가 본인이 생성한 항목을 삭제할 수 없음 (403). `inventory:delete` 권한이 researcher 역할에 없거나, 소유자 체크 로직에 문제 가능성.

### 3.2 개선 권고

1. **JWT 만료 시간**: 현재 15분. 개발/테스트 환경에서는 최소 1시간 권고.
2. **통합검색 안정성**: OpenSearch 연결 타임아웃 처리 및 헬스체크 강화 필요.
3. **API 문서화**: Swagger/OpenAPI 스펙과 실제 Zod 스키마 간 동기화 필요.
4. **reviewer 역할 권한**: reviewer에게 `note:write` 권한이 없어 노트 생성 불가 — 테스트 시나리오상 reviewer 노트가 필요한 경우 admin이 할당하는 워크플로 필요.

### 3.3 정상 작동 확인된 핵심 기능

- 인증/JWT 발급 및 갱신
- RBAC 권한 체크 (requireAuth, requirePermission, requireRole)
- 노트 CRUD + 상태 전환 (draft↔in_progress→locked→signed)
- 전자서명 (해시체인) + 서명 무효화
- 관리자 잠금 해제
- 실시간 협업 (WebSocket broadcast + Redis pub/sub)
- 템플릿 생성/삭제
- 노트-인벤토리 연결/해제
- 인벤토리 CRUD + 바코드 중복 검증
- 대시보드 (개인/조직) + 재고 경고
- 감사로그 조회 + 수정/삭제 불가
- 실시간 알림 (SSE) + 미읽음 카운트
- 멀티테넌시 (orgId 기반 데이터 격리)
