## 인증/사용자

### #1 로그인 및 세션 관리

```mermaid
sequenceDiagram
    participant U as 사용자
    participant FE as 프론트엔드
    participant GW as API Gateway
    participant Auth as Auth Service

    U->>FE: 이메일/비밀번호 입력
    FE->>GW: POST /api/auth/login
    GW->>Auth: POST /api/auth/login
    Auth->>Auth: 비밀번호 검증 (bcrypt)
    Auth-->>GW: { token, refreshToken, user }
    GW-->>FE: 로그인 성공

    FE->>GW: POST /api/auth/session
    Note over GW: refreshToken을 HttpOnly 쿠키에 저장<br/>(labnote_rt, Max-Age=28800)
    GW-->>FE: 세션 설정 완료

    Note over FE: 이후 모든 요청에 Authorization: Bearer 토큰 포함

    rect rgb(255, 245, 230)
        Note over FE,GW: 세션 갱신 (토큰 만료 전)
        FE->>GW: POST /api/auth/session/refresh
        GW->>GW: 쿠키에서 refreshToken 추출
        GW->>Auth: POST /api/auth/refresh
        Auth-->>GW: 새 token + refreshToken
        GW-->>FE: 새 토큰 + 쿠키 갱신
    end
```

## 연구노트

### #4 연구노트 작성 및 편집

```mermaid
sequenceDiagram
    participant U as 사용자
    participant GW as API Gateway
    participant ELN as ELN Service
    participant Search as Search Service
    participant Sig as Signature-Audit Service

    U->>GW: POST /api/notes
    GW->>ELN: 노트 생성 요청
    ELN->>ELN: Note 생성 (status=draft)
    ELN->>ELN: NoteRevision 생성 (revision=1)
    ELN-)Search: POST /api/search/index
    Note over ELN,Search: x-internal-secret<br/>domainType: "NOTE"
    ELN-)Sig: POST /api/audit/internal (감사로그)
    ELN-->>GW: { ok: true, data: note }
    GW-->>U: 노트 생성 완료

    rect rgb(240, 248, 255)
        Note over U,Sig: 노트 수정
        U->>GW: PUT /api/notes/:id
        GW->>ELN: 노트 수정 요청
        ELN->>ELN: signed/locked 상태 체크 → 수정 불가 시 에러
        ELN->>ELN: Note 업데이트
        ELN->>ELN: NoteRevision 생성 (revision 자동 증가)
        ELN-)Search: POST /api/search/index (재인덱싱)
        ELN-)Sig: POST /api/audit/internal
        ELN-->>GW: 수정 완료
    end
```

### #5 실시간 협업 편집

```mermaid
sequenceDiagram
    participant U1 as 사용자A
    participant U2 as 사용자B
    participant GW as API Gateway
    participant Collab as Collab Service
    participant ELN as ELN Service
    participant Redis as Redis

    U1->>GW: WS /collab/notes/:noteId?token=JWT
    GW->>Collab: WebSocket 프록시
    Collab->>Collab: JWT 검증 (자체 수행)
    Collab->>ELN: GET /api/notes/:noteId (상태 확인)
    Note over Collab,ELN: x-internal-secret
    alt signed/locked
        Collab-->>U1: { type: "read-only" }
    end
    Collab->>Collab: Room 입장 + 색상 배정 (8색)
    Collab-->>U1: { type: "joined", users: [...] }

    U2->>GW: WS /collab/notes/:noteId?token=JWT
    GW->>Collab: WebSocket 프록시
    Collab-->>U1: { type: "user-joined", userId, colorIdx }
    Collab-->>U2: { type: "joined", users: [...] }

    rect rgb(240, 248, 255)
        Note over U1,Redis: 실시간 편집 동기화
        U1->>Collab: { type: "content-update", content }
        Collab->>Collab: 로컬 broadcast (같은 인스턴스)
        Collab->>Redis: PUBLISH labnote:collab
        Note over Redis: 멀티 인스턴스 지원
        Collab-->>U2: { type: "content-update", content }
    end

    U1->>Collab: 연결 종료
    Collab-->>U2: { type: "user-left", userId }
```

### #6 연구노트 상태 전환

```mermaid
sequenceDiagram
    participant U as 사용자
    participant GW as API Gateway
    participant ELN as ELN Service
    participant Sig as Signature-Audit Service
    participant Redis as Redis

    U->>GW: PATCH /api/notes/:id/status { status: "in_progress" }
    GW->>ELN: 상태 변경 요청
    ELN->>ELN: 전환 규칙 검증 (ALLOWED_STATUS_TRANSITIONS)
    Note over ELN: draft→in_progress ✓<br/>in_progress→draft ✓<br/>in_progress→locked (reviewer/admin만)
    ELN->>ELN: DB 트랜잭션 (FOR UPDATE)
    ELN->>ELN: NoteStatusHistory 기록

    ELN-)Sig: POST /api/audit/internal (감사로그)
    ELN-)Redis: PUBLISH labnote:note-status
    Note over Redis: collab-service 캐시 무효화

    alt in_progress → locked (잠금)
        ELN-)Sig: POST /api/notifications/internal
        Note over Sig: type: NOTE_LOCKED<br/>recipient: 노트 작성자
    end

    ELN-->>GW: { ok: true, data: note }
    GW-->>U: 상태 변경 완료
```

### #7 연구노트 최종 전자서명

```mermaid
sequenceDiagram
    participant U as 검토자/관리자
    participant GW as API Gateway
    participant Sig as Signature-Audit Service
    participant Auth as Auth Service
    participant ELN as ELN Service
    participant Redis as Redis

    U->>GW: POST /api/signatures/sign/:noteId { password }
    GW->>Sig: 서명 요청

    Sig->>Sig: 권한 검증 (reviewer/admin/team-leader)
    Sig->>Sig: 자기 노트 서명 불가 체크 (admin 제외)

    Sig->>Auth: POST /api/auth/internal/verify-password
    Note over Sig,Auth: x-internal-secret<br/>{ userId, password }
    Auth-->>Sig: 비밀번호 확인

    Sig->>Sig: 해시 체인 생성
    Note over Sig: sha256(noteId:signerId:timestamp:prevHash)
    Sig->>Sig: Signature + AuditLog DB 저장

    rect rgb(255, 245, 230)
        Note over Sig,ELN: 노트 상태 전환 (in_progress → signed)
        Sig->>Redis: XADD labnote:events (NOTE_SIGNED)
        Note over Redis: 1차: Redis Stream 이벤트
        Redis->>ELN: Event Consumer 소비
        ELN->>ELN: 상태 전환 (system 권한)
    end

    rect rgb(255, 240, 240)
        Note over Sig,ELN: Redis 실패 시 폴백
        Sig->>ELN: PATCH /api/notes/:noteId/status
        Note over Sig,ELN: x-user-role=system<br/>{ status: "signed" }
    end

    Sig-)Sig: POST /api/notifications/internal
    Note over Sig: type: NOTE_SIGNED<br/>recipient: 노트 작성자
    Sig->>Redis: PUBLISH notifications:{userId}

    Sig-->>GW: { ok: true, data: signature }
    GW-->>U: 서명 완료
```

### #8 관리자 잠금 해제

```mermaid
sequenceDiagram
    participant Admin as 관리자
    participant GW as API Gateway
    participant ELN as ELN Service
    participant Auth as Auth Service
    participant Sig as Signature-Audit Service

    Admin->>GW: POST /api/notes/:id/admin-unlock
    Note over GW: requireRole(ADMIN) + requirePermission(NOTE_UNLOCK)
    GW->>ELN: 잠금 해제 요청 { adminPassword, reason }

    ELN->>ELN: 노트 상태 확인 (locked만 가능)

    Auth-->>ELN: 비밀번호 확인

    ELN->>ELN: 상태 전환 (locked → draft)
    ELN->>ELN: NoteStatusHistory 기록 (isAdminAction=true)

    ELN-)Sig: POST /api/audit/internal
    Note over Sig: action: "note.admin_unlocked"<br/>details: { reason }

    ELN-)Sig: POST /api/notifications/internal
    Note over Sig: type: NOTE_UNLOCKED<br/>recipient: 노트 작성자

    ELN-->>GW: { ok: true }
    GW-->>Admin: 잠금 해제 완료
```

```mermaid
        Sched-->>GW: 409 "시간 충돌"
        GW-->>U: 충돌 안내 표시
    else 정상
        Sched->>Sched: Booking 생성 (status=PENDING)
        Sched-->>GW: { ok: true, data: booking }
        GW-->>U: 예약 생성 완료 (대기 상태)
    end

    U->>GW: GET /api/scheduler/bookings?from=...&to=...
    GW->>Sched: 주간 예약 조회
    Sched-->>GW: 예약 목록
    GW-->>U: 캘린더 표시 (8:00~17:00)
```

### #23 실시간 알림

```mermaid
sequenceDiagram

        end

            GW-->>FE: SSE heartbeat
        end
    end

    rect rgb(255, 245, 250)

        FE->>GW: PATCH /api/notifications/:id/read
        GW->>Sig: 읽음 처리
        Sig->>Redis: DECR notif-unread:{userId}

        FE->>GW: PATCH /api/notifications/read-all
        GW->>Sig: 전체 읽음
        Sig->>Redis: DEL notif-unread:{userId}
    end
```
